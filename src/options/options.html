Patterns

Text matches literally. Glob is path-flavoured: * stays inside one segment, ** crosses separators, ? is one character. Regex is a raw JavaScript regular expression (g is always applied). Those three match text; a Locator matches a whole element.

A locator is a bare XPath (//code, (//td)[2], //a/@href), a bare CSS selector (.build > .id), or Selenium's strategy=value form, so a locator can be pasted straight out of a page object: xpath=, css=, id=, name=, class name=, tag name=, link text=, partial link text=. The element's text is what gets copied; XPath may also select an attribute or text node directly.

Within combines the two halves: give a text pattern a locator and it only matches inside what that locator selects. Against elements the pattern runs over their text and highlights each substring; against an attribute or a form control it runs over that single value and the hit sits on the owning element. So Within //a/@href with pattern /browse/([A-Z]+-\d+) and Copy as $1 turns every ticket link on the page into a one-click copy of just the ticket key. Within does not apply to the Locator type, which already is one.

Copy as rewrites what lands on the clipboard: $0 is the whole match and $$ a literal $. Text patterns add $1…$9 and $<name> for capture groups; locators add $@attr for an attribute of the matched element, e.g. $@data-id. Flags apply to regexes only. Sites is a comma-separated list of URL globs, e.g. *.example.com/*.
